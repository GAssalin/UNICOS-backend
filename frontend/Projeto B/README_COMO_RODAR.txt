Projeto B v5 - CRUD Estoque Dashboard

Como rodar:
1) Abra o terminal dentro da pasta "Projeto B"
2) Rode: npm install
3) Rode: npm run dev

Nesta versão:
- CRUD completo de Produtos
- Campos: SKU, código de barras, fornecedor, categoria, unidade, estoque mínimo, preços
- Estoque calculado automaticamente por movimentações
- Tela única de Movimentações para Entrada/Saída
- Dashboard com gráficos reais em CSS/HTML, baseado nos dados salvos
- Dados salvos no localStorage do navegador

Observação:
Se quiser limpar todos os dados de teste, abra o DevTools do navegador > Application > Local Storage e remova as chaves unicos_products_v1 e unicos_movements_v1.
